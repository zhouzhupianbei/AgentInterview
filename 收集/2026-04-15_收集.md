## 🤖 主题四：大模型开发面试 (LLM Developer Interview)

### 核心知识点

#### 1. LLM 基础
- Transformer 架构详解 (Self-Attention, Multi-Head Attention)
- GPT 系列模型演变 (GPT-3 → GPT-4 → GPT-4o)
- BERT vs GPT 架构对比
- Tokenization 策略 (BPE, WordPiece, SentencePiece)

#### 2. 模型训练与微调
- **LoRA (Low-Rank Adaptation)**: 参数高效微调方法
- **RLHF (Reinforcement Learning from Human Feedback)**: 人类反馈强化学习
- **DPO (Direct Preference Optimization)**: 直接偏好优化
- 数据准备与标注策略

#### 3. 推理优化
- **KV Cache**: 键值缓存加速推理
- **量化 (Quantization)**: INT8/INT4 量化
- **投机采样 (Speculative Sampling)**: 加速文本生成
- **Continuous Batching**: 连续批处理
- **vLLM**: 高效推理引擎

#### 4. RAG 系统
- 向量数据库 (Milvus, Pinecone, Weaviate)
- Embedding 模型选择
- 混合检索 (Hybrid Search)
- Rerank 策略
- GraphRAG 知识图谱增强

#### 5. AI Agent
- **ReAct 模式**: Reasoning + Acting
- **Function Calling**: 工具调用机制
- **多 Agent 协作**: AutoGen, CrewAI
- **MCP 协议**: Model Context Protocol
- **记忆管理**: 短期/长期记忆、上下文窗口优化

### 面试高频题分类

| 难度 | 主题 | 示例问题 |
|------|------|----------|
| ⭐⭐ | LLM 基础 | 解释 Temperature 参数的作用 |
| ⭐⭐⭐ | RAG 系统 | 如何解决 RAG 的幻觉问题？ |
| ⭐⭐⭐ | Agent | ReAct 模式的工作原理是什么？ |
| ⭐⭐⭐⭐ | 推理优化 | KV Cache 如何加速推理？ |
| ⭐⭐⭐⭐⭐ | 架构设计 | 设计一个支持 10 万 QPS 的 RAG 系统 |
