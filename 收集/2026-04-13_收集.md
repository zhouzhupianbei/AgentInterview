## 一、AI 面试 & AIGC Interview

### 核心知识点

1. **AI 大模型本质**
   - 以统计规律代替逻辑规律，以相关性代替因果性
   - 通过海量参数的函数拟合输入输出算法
   - 技术原理：通过数据集获得统计规律，通过统计规律进行插值输出

2. **AI Infra 定义**
   - 并非单一技术模块，而是通过硬件与软件的深度协同
   - 构建支撑 AI 大模型任务全流程的技术底座
   - 核心特征："垂直整合"，从物理硬件到上层工具形成闭环

3. **AI Agent 工程师核心能力** (来自知乎热门讨论)
   - **误区**: 很多人以为 AI Agent 工程师就是"会调用 LangChain API 的人"——这是错误的
   - **实际需要的能力**:
     - 深入理解 LLM 工作原理和限制
     - 掌握 RAG 架构和实现
     - 熟悉 Agent 设计模式（规划、记忆、工具使用）
     - 具备系统设计和工程化能力
     - 了解模型微调和优化技术

4. **2026 年 AI 技术趋势**
   - 模型蒸馏技术受到关注（DeepSeek 的 GRPO 是高效替代方案）
   - 国内 AI 大模型已近 80 个，竞争激烈
   - AI 监控和行为分析技术应用扩展

### 面试常见问题方向

- LLM 工作原理和 next-token prediction 机制
- RAG 架构设计和实现细节
- Agent 规划能力和工具调用
- 模型优化（量化、剪枝、蒸馏）
- AI 应用工程化部署

## 四、大模型开发面试

### 核心技术问题

1. **LLM 基础原理**
   - 为什么 LLM 仅预测下一词就能"涌现"出高级能力？
   - LLM 产生幻觉的原因分析
   - LLM 数字运算不准确的底层原因（数字对齐问题）

2. **推理能力**
   - LLM 复杂推理的主要方法
   - System 1 vs System 2 思维模式
   - 推理不可靠、无法形成稳定世界模型的问题

3. **部署和优化**
   - 模型量化（减少数字精度以节省内存）
   - 模型修剪（移除不重要的权重）
   - 模型蒸馏（知识蒸馏技术）
   - 有效管理计算资源

4. **应用开发**
   - RAG 解决 LLM 两大痛点：减少幻觉、提供最新信息
   - 领域微调策略
   - Prompt 工程最佳实践
   - Agent 设计和实现

### 2026 年面试趋势

- 更注重实际工程能力而非纯理论
- 强调 RAG 和 Agent 实战经验
- 关注模型优化和部署能力
- 重视系统设计和架构思维
