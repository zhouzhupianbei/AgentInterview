# 06-资源汇总

> 这一章不是简单罗列课程、书籍和项目，而是帮你回答一个更实际的问题：**如果我要真正把 AI 开发能力补起来，哪些资源值得看，应该先看什么，后看什么？**

这里的资源会尽量围绕“学习价值”和“可执行性”来整理，而不是只看热度。

---

## 怎么读这一章

### 如果你刚入门
优先看学习路线图，再挑中文课程和入门项目，不要一上来就冲最热框架。

### 如果你已经在做项目
优先看开源项目推荐和工程实践类资料，重点关注：
- RAG
- Agent
- 工程化
- 部署与评估

### 如果你在准备面试
优先看：
- 学习路线图
- 开源项目推荐
- 微信文章精选

因为面试里经常会问：
- 你平时怎么学习
- 你关注哪些框架
- 你怎么看某个新趋势

## 6.1 学习路线图

### 0 → 1 入门（1-2 个月）

```
第 1-2 周：Python 基础
├── 语法基础
├── 数据结构（列表、字典、集合）
├── 函数和模块
└── 面向对象

第 3-4 周：深度学习基础
├── 神经网络基础
├── PyTorch/TensorFlow
├── CNN/RNN
└── 实战：图像分类

第 5-6 周：Transformer 入门
├── Self-Attention 原理
├── Transformer 架构
├── BERT/GPT 简介
└── 实战：文本分类

第 7-8 周：LLM 应用开发
├── Prompt Engineering
├── LangChain 基础
├── API 调用
└── 实战：简单问答机器人
```

### 1 → 10 进阶（3-6 个月）

```
第 1-2 月：深入理解 LLM
├── Transformer 细节（RoPE、SwiGLU）
├── 主流模型对比（LLaMA、Qwen、Claude）
├── Tokenization 技术
└── 实战：从零实现 Transformer

第 3-4 月：RAG 与 Agent
├── 向量数据库（Chroma、FAISS）
├── RAG 优化技巧
├── Agent 设计模式
└── 实战：企业知识库系统

第 5-6 月：微调与部署
├── LoRA/QLoRA 微调
├── 模型量化
├── vLLM/TGI部署
└── 实战：微调领域模型
```

### 10 → 100 精通（持续）

```
方向选择：
├── 算法研究
│   ├── 跟进最新论文
│   ├── 复现 SOTA 模型
│   └── 参与开源项目
│
├── 工程架构
│   ├── 高并发系统设计
│   ├── 性能优化
│   └── 生产环境部署
│
└── 产品应用
    ├── 用户需求分析
    ├── 产品设计
    └── 商业化落地
```

## 6.10 2026 新技术与标准

### Model Context Protocol (MCP)

**什么是 MCP**：2026 年新兴的开放协议，用于 LLM 应用与外部数据源/工具的标准集成

**核心优势**：
- 标准化接口：统一工具调用方式
- 跨平台：支持 Python、TypeScript、Java、Go 等多语言
- 安全性：内置权限控制
- 生态系统：快速增长的 MCP 服务器库

**学习资源**：
- [MCP 官方文档](https://modelcontextprotocol.io)
- [MCP 规范](https://modelcontextprotocol.io/specification/latest)
- [MCP Python SDK](https://github.com/modelcontextprotocol/python-sdk)
- [MCP 服务器列表](https://github.com/modelcontextprotocol/servers)

**面试考点**：
- MCP 与 Function Calling 的区别
- 如何实现 MCP 客户端/服务器
- MCP 的安全模型

---

### GraphRAG

**什么是 GraphRAG**：微软研究院推出的基于知识图谱的 RAG 增强系统

**核心优势**：
- 实体关系抽取：自动构建知识图谱
- 全局理解：不仅检索片段，还理解整体结构
- 复杂查询：支持多跳推理
- 减少幻觉：基于图谱事实

**适用场景**：
- 长文档分析（报告、论文）
- 跨文档推理
- 需要全局理解的问答

**学习资源**：
- [GraphRAG 官方文档](https://microsoft.github.io/graphrag)
- [GraphRAG 论文](https://arxiv.org/pdf/2404.16130)
- [GraphRAG 快速开始](https://microsoft.github.io/graphrag/get_started/)

**面试考点**：
- GraphRAG vs 传统 RAG
- 知识图谱构建流程
- GraphRAG 的成本优化

---

### Deep Agents (LangChain 2026 新方向)

**什么是 Deep Agents**：LangChain 2026 年推出的深度 Agent 框架

**核心特性**：
- 子代理系统：主代理可调用专业子代理
- 文件系统集成：直接读写文件
- 长期规划：支持多步骤复杂任务
- 持久化执行：支持长时间运行

**学习资源**：
- [Deep Agents GitHub](https://github.com/langchain-ai/deepagents)
- [LangGraph 文档](https://docs.langchain.com/oss/python/langgraph/overview)

---

### Agentic RAG

**概念**：将 Agent 能力融入 RAG 流程

**典型流程**：
```
用户问题 → Agent 分析 → 多轮检索 → 结果整合 → 答案
              ↓
        决定检索策略
```

**关键能力**：
- 自主决定检索次数
- 动态调整检索策略
- 多源信息融合
- 自我验证
