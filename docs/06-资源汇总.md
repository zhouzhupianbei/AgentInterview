## 6.1 学习路线图

### 0 → 1 入门（1-2 个月）

```
第 1-2 周：Python 基础
├── 语法基础
├── 数据结构（列表、字典、集合）
├── 函数和模块
└── 面向对象

第 3-4 周：深度学习基础
├── 神经网络基础
├── PyTorch/TensorFlow
├── CNN/RNN
└── 实战：图像分类

第 5-6 周：Transformer 入门
├── Self-Attention 原理
├── Transformer 架构
├── BERT/GPT 简介
└── 实战：文本分类

第 7-8 周：LLM 应用开发
├── Prompt Engineering
├── LangChain 基础
├── API 调用
└── 实战：简单问答机器人
```

### 1 → 10 进阶（3-6 个月）

```
第 1-2 月：深入理解 LLM
├── Transformer 细节（RoPE、SwiGLU）
├── 主流模型对比（LLaMA、Qwen、Claude）
├── Tokenization 技术
└── 实战：从零实现 Transformer

第 3-4 月：RAG 与 Agent
├── 向量数据库（Chroma、FAISS）
├── RAG 优化技巧
├── Agent 设计模式
└── 实战：企业知识库系统

第 5-6 月：微调与部署
├── LoRA/QLoRA 微调
├── 模型量化
├── vLLM/TGI部署
└── 实战：微调领域模型
```

### 10 → 100 精通（持续）

```
方向选择：
├── 算法研究
│   ├── 跟进最新论文
│   ├── 复现 SOTA 模型
│   └── 参与开源项目
│
├── 工程架构
│   ├── 高并发系统设计
│   ├── 性能优化
│   └── 生产环境部署
│
└── 产品应用
    ├── 用户需求分析
    ├── 产品设计
    └── 商业化落地
```

## 6.8 求职时间线

### 校招（以 2027 届为例）

```
2026.3-5 月：准备期
├── 刷题（LeetCode 300 题）
├── 复习基础（ML/DL/Transformer）
└── 准备项目（2-3 个完整项目）

2026.6-8 月：提前批
├── 投递大厂提前批
├── 参加笔试面试
└── 争取 early offer

2026.9-11 月：秋招高峰
├── 海投简历
├── 密集面试
└── 比较 offer

2026.12-2027.2 月：补录
├── 查漏补缺
└── 最终决定
```

### 社招

```
准备期（1-2 月）：
├── 更新简历
├── 整理项目经历
├── 刷题保持手感
└── 了解市场行情

投递期（持续）：
├── 内推优先
├── 猎头渠道
├── 招聘平台
└── 公司官网

面试期（2-4 周）：
├── 技术面（2-3 轮）
├── 主管面（1 轮）
├── HR 面（1 轮）
└── 谈薪

入职期（1-2 月）：
├── 背景调查
├── 体检
├── 离职交接
└── 入职
```
