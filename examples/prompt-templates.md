# Prompt 模板库

> 常用 Prompt 模板，可直接复用

---

## 1. 代码相关

### 代码审查

```markdown
# 角色
你是一位资深代码审查专家，有 10 年大厂经验

# 任务
审查以下代码，关注：
- 代码规范和风格
- 潜在 bug 和边界情况
- 性能问题
- 安全漏洞
- 可维护性和可读性

# 输出格式
## 问题汇总
### 🔴 严重问题
1. [行号] 问题描述 + 修复建议

### 🟡 警告
2. [行号] ...

### 💡 改进建议
3. ...

## 整体评价
[1-5 星评分] + 简短评价

# 代码
```[语言]
[代码内容]
```
```

---

### 代码生成

```markdown
# 任务
实现以下功能：[功能描述]

# 要求
- 语言：[Python/JavaScript/等]
- 包含完整的错误处理
- 添加详细的注释
- 包含单元测试
- 遵循 [PEP8/ESLint] 规范

# 示例输入输出
输入：[示例]
输出：[示例]

# 约束
- 时间复杂度：[要求]
- 空间复杂度：[要求]
- 依赖：[允许的库]
```

---

### 代码解释

```markdown
# 任务
解释以下代码的功能和工作原理

# 输出要求
1. 用通俗语言说明代码做了什么
2. 逐段解释关键逻辑
3. 说明输入输出
4. 指出可能的优化点

# 代码
```[语言]
[代码内容]
```
```

## 2. 文档写作

### 技术文档

```markdown
# 角色
你是一位资深技术作家，擅长写清晰的技术文档

# 任务
为以下主题撰写技术文档：[主题]

# 目标读者
[初级开发者/高级开发者/技术管理者]

# 文档结构
1. 概述（解决的问题）
2. 核心概念
3. 使用指南
4. API 参考
5. 最佳实践
6. 常见问题

# 要求
- 语言简洁清晰
- 包含代码示例
- 使用图表辅助说明
- 避免行话和模糊表述
```

---

### README 生成

```markdown
# 任务
为以下项目生成 README.md

# 项目信息
- 名称：[项目名]
- 简介：[一句话描述]
- 技术栈：[列表]
- 主要功能：[列表]

# 必需章节
- 项目介绍
- 快速开始
- 功能特性
- 使用示例
- 安装指南
- 贡献指南
- License

# 风格要求
- 使用 emoji 增加可读性
- 包含徽章（badge）
- 添加截图/GIF 占位符
```

## 3. 学习辅导

### 概念解释

```markdown
# 角色
你是一位耐心的老师，擅长用简单语言解释复杂概念

# 任务
解释以下概念：[概念名称]

# 输出要求
1. 一句话定义（15 字以内）
2. 类比说明（用生活中的例子）
3. 核心原理（技术细节）
4. 应用场景（3-5 个）
5. 常见误区
6. 延伸阅读推荐

# 目标读者
[高中生/大学生/转行者/等]
```

---

### 学习路线

```markdown
# 任务
为想学习 [主题] 的人制定学习路线

# 学习者背景
- 当前水平：[描述]
- 可用时间：[每天 X 小时]
- 目标：[找工作/提升技能/等]

# 输出要求
1. 分阶段学习计划（每周）
2. 每个阶段的学习资源
3. 实践项目建议
4. 自我检测方法
5. 常见困难和解决方案
```

## 4. 面试准备

### 模拟面试

```markdown
# 角色
你是一位大厂技术面试官，有 10 年面试经验

# 任务
对候选人进行模拟面试

# 面试岗位
[AI 工程师/后端开发/等]

# 面试流程
1. 自我介绍（2 分钟）
2. 项目深挖（10 分钟）
3. 技术问题（15 分钟）
4. 代码题（15 分钟）
5. 反向提问（5 分钟）

# 要求
- 问题要有针对性
- 根据回答追问
- 最后给出反馈和改进建议
- 评估维度：技术深度、沟通能力、问题解决

# 候选人简历
[简历内容]
```

---

### 行为面试准备

```markdown
# 任务
帮助准备行为面试问题

# 目标公司
[公司名]

# 输出要求
1. 预测 10 个可能的行为面试问题
2. 为每个问题提供回答框架（STAR）
3. 给出 3 个个人经历示例
4. 指出常见错误和注意事项

# 个人背景
[工作经历、项目经验等]
```

## 5. 产品设计

### 需求分析

```markdown
# 角色
你是一位资深产品经理

# 任务
分析以下产品需求

# 需求描述
[用户需求或痛点]

# 输出要求
1. 用户画像（目标用户是谁）
2. 使用场景（何时何地为何使用）
3. 核心功能（Must have）
4. 辅助功能（Nice to have）
5. 成功指标（如何衡量成功）
6. 潜在风险和挑战
7. 竞品分析
```

---

### PRD 生成

```markdown
# 任务
撰写产品需求文档（PRD）

# 产品信息
- 产品名称：[名称]
- 目标用户：[描述]
- 核心价值：[一句话]

# PRD 结构
1. 文档概述
2. 产品背景
3. 目标用户
4. 功能需求
   - 功能列表
   - 详细需求说明
   - 用户故事
5. 非功能需求
   - 性能要求
   - 安全要求
6. 数据需求
7. 上线计划
8. 风险与应对
```

## 7. 创意写作

### 头脑风暴

```markdown
# 任务
为以下主题进行头脑风暴

# 主题
[主题描述]

# 要求
1. 产生 20 个创意点子
2. 每个点子 1-2 句话描述
3. 覆盖不同角度和方向
4. 包含常规和创新的想法
5. 标注每个点子的可行性（高/中/低）
```

---

### 故事创作

```markdown
# 任务
创作一个短篇故事

# 要求
- 主题：[主题]
- 字数：[X 字]
- 风格：[科幻/悬疑/温情/等]
- 包含：[必须元素]
- 目标读者：[描述]

# 故事结构
1. 开端（引入角色和背景）
2. 发展（冲突出现）
3. 高潮（冲突激化）
4. 结局（问题解决）
```

## 8. 翻译润色

### 技术翻译

```markdown
# 任务
翻译以下技术文档

# 源语言
[语言]

# 目标语言
[语言]

# 要求
- 准确传达技术含义
- 使用行业标准术语
- 保持原文结构
- 对难懂概念添加注释
- 保留代码和专有名词

# 原文
[内容]
```

---

### 文本润色

```markdown
# 任务
润色以下文本

# 原文
[内容]

# 要求
- 改进语言流畅度
- 修正语法错误
- 优化句子结构
- 提升专业性
- 保持原意不变

# 目标风格
[正式/ casual/ 学术/ 商务]
```

---

## 使用建议

1. **根据场景选择模板**：不要生搬硬套
2. **调整细节**：根据你的具体需求修改
3. **迭代优化**：记录哪些 prompt 效果好
4. **建立个人库**：积累自己的 prompt 库
