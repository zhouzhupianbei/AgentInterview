## 维护思路

这轮维护的核心思路是：**把仓库往"能力培养型知识库"的方向再推一步**。

什么是能力培养型知识库？
- 不只是"有什么知识"，而是"怎么用知识"
- 不只是"题库答案"，而是"表达方法"

这轮新增的面试表达专题和项目复盘模板，就是想让读者看完后能回答：
- 概念题怎么讲得有层次
- 项目题怎么讲得有重点
- 判断题怎么讲得有判断
- 系统设计题怎么讲得完整
