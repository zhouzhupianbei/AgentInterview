# 知识卡片｜项目建议章节重构

## 这次重构的核心判断

- `05-项目建议.md` 不应该只是项目列表，而应该承担“作品集指导”和“项目叙事训练”的角色。
- 对 AI 面试读者来说，项目的价值不在数量，而在于是否能映射能力、形成证据、支持表达。
- 项目章节最该补的是“怎么选、怎么做、怎么讲”，而不是继续平铺更多项目题目。

## 章节的新定位

- 帮读者选择更值得做的项目
- 帮读者理解不同类型项目分别体现什么能力
- 帮读者把项目写进简历、讲进面试

## 下一步可继续深化的方向

- 补一篇“如何讲自己的 AI 项目”专题正文
- 将 3 个典型项目展开成完整案例
- 给每类项目补 README 结构示例与简历写法示例
