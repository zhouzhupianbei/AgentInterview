这是一篇全新的专题正文，回答一个很多人心里没底的问题：

## 维护思路

这轮维护的核心思路是：**继续把仓库往"成长型知识库"的方向推**。

什么是成长型知识库？
- 不只是"有什么资料"，而是"该怎么学"
- 不只是"题库答案"，而是"表达方法"
- 不只是"概念定义"，而是"工程判断"

这轮新增的学习路径专题，就是想让读者看完后能回答：
- 我现在在哪
- 下一步该补什么
- 怎么验证自己真的学会了
